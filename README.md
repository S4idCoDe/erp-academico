## Descripción

Sistema de venta de tickets en línea orientado a facilitar la
consulta de eventos y la gestión de entradas desde una plataforma
organizada y accesible.

## Objetivo

Desarrollar una aplicación que permita administrar eventos y
apoyar el proceso de venta de tickets en línea.

## Funcionalidades propuestas

| Funcionalidad | Descripción |
| :--- | :--- |
| Consulta de eventos | Visualizar los eventos disponibles. |
| Compra de tickets | Seleccionar y adquirir entradas. |
| Gestión de usuarios | Administrar la información de los usuarios. |
| Administración de eventos | Registrar y gestionar eventos y entradas. |
| Consulta de ventas | Revisar la información de las ventas realizadas. |

> Las funcionalidades pueden cambiar durante el desarrollo.
